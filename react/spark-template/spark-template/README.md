# Whisper Notes 前端

React + Vite 的端到端加密 Markdown 笔记界面。创建保险库后，浏览器使用 PBKDF2-SHA-256（600,000 次）从加密密码派生不可导出的 AES-256-GCM 密钥；标题和 Markdown 正文加密后才发往后端。

保险库支持自定义名称和多库下拉切换；下拉列表的保险库 ID 从数据库获取，库名称仍在浏览器端加密后存入云端。本机只缓存成功解锁过的显示名称，不保存密码或密钥。

## 启动

先启动 `../spark-template-backend`，再执行：

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

访问 `http://127.0.0.1:5000`。Vite 会将 `/api` 代理到 `http://127.0.0.1:3100`。

## 数据安全边界

- 加密密码和派生密钥只存在于浏览器内存，不写入服务器或浏览器存储。
- 保险库列表由后端数据库提供；浏览器只缓存已解锁保险库的显示名称，不保存密码、访问令牌或派生密钥。
- 每次保存使用新的 96 位随机 IV；AES-GCM 附加数据绑定保险库 ID、笔记 ID和协议版本。
- Markdown 预览经过 DOMPurify 清洗，避免笔记中的 HTML 脚本执行。
- 忘记加密密码无法恢复数据；生产部署必须使用 HTTPS。

右上角“组件实验室”对应 `/#components`，按 Radix Primitives 官方目录展示全部 30 个组件：左侧为分类导航，右侧提供可交互演示、中文说明和官方文档入口。示例直接使用官方 `radix-ui` 包，项目业务界面仍可继续使用 `src/components/ui` 中的 shadcn 封装。

## Markdown 编辑器

- 桌面端为“笔记列表 + Markdown 源码 + 实时预览”三栏布局。
- 源码和预览之间的分隔线可拖动调整，长文档支持双向同步滚动。
- 快捷工具栏支持标题、粗体、斜体、引用、列表、任务、代码、链接和分隔线。
- 回车会自动续写无序列表、有序列表、任务列表和引用；空项目再次回车退出，代码围栏自动闭合。
- 代码围栏支持语法高亮；输入语言前缀会弹出 Java、JavaScript、JSON 等候选，可用方向键和 Enter/Tab 选择。
- 常用 Markdown 工具齐全：H1-H3、粗体、斜体、删除线、引用、列表、任务、代码、链接、图片、表格和分隔线。
- 支持 Ctrl+B/Ctrl+I/Ctrl+K/Ctrl+Shift+X、Ctrl+Alt+1/2/3，以及 Tab/Shift+Tab 缩进；预览任务可直接勾选，代码块可一键复制。
- 每篇笔记维护独立的正文撤销/重做历史，支持工具栏以及 Ctrl+Z、Ctrl+Shift+Z、Ctrl+Y，最多保留 100 个历史节点。
- 预览侧自动生成标题大纲，可点击跳转。
- 沉浸模式隐藏应用导航和笔记列表，按 `Esc` 退出。
- 移动端使用编辑/预览标签切换，并通过抽屉访问笔记列表。
